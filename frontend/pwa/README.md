# 📱 PWA — Progressive Web App

## المهمة
تحويل English Quest إلى تطبيق قابل للتثبيت على الهاتف والتابلت.

## المتطلبات
- [ ] manifest.json (اسم، أيقونات، ألوان)
- [ ] Service Worker (تخزين مؤقت + عمل بدون نت)
- [ ] App Shell architecture
- [ ] أيقونات بأحجام متعددة (192px, 512px)
- [ ] Splash screen
- [ ] اختبار Lighthouse PWA score ≥ 90
